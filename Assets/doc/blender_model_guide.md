# Blenderモデル実装ガイド & 演出アイデア集
## 流れるオブジェクト塗りゲーム（2026大宮フェス）

---

## このドキュメントについて

プリミティブ（Cube/Sphere）で動作確認ができたあと、  
**Blenderで作った3Dモデルに差し替えるための準備事項**と、  
**演出をリッチにするためのアイデア集**をまとめています。

実装方法は後で追記予定。まずはアイデアと方針を整理する。

---

## PART 1：Blenderモデルの要件（差し替えに必要なこと）

---

### 1-1. オブジェクト（流れてくるターゲット）

#### ✅ 必須要件

| 項目 | 内容 |
|---|---|
| UV展開 | **必須**。UV が展開されていないとインクが塗れない |
| UV重複なし | 各面が UV 空間 (0〜1) に収まり、重複していないこと |
| ポリゴン数 | 1000面以下推奨（複数同時表示するため軽量に） |
| 単一メッシュ | 複数パーツに分けない（1オブジェクト = 1メッシュ） |
| スケール適用 | Blender で Ctrl+A → Scale を適用してからエクスポート |
| 中心点 | オブジェクトの重心付近に設定（Shift+Ctrl+Alt+C） |

#### ✅ エクスポート設定（Blender → Unity）

- 形式：**FBX**（推奨）または **glTF/GLB**
- Apply Transform：**ON**（Blenderの座標系をUnityに合わせる）
- Mesh：**UVs チェックON**、**Normals チェックON**

#### ✅ Unity での MeshCollider 設定

現在 `ObjectSpawner.cs` はプリミティブのメッシュを MeshCollider に使っています。  
Blenderモデルに差し替えるときも同じ手順：

```
1. FBXをインポート
2. Prefab を作成
3. Prefab に MeshCollider をアタッチ
4. sharedMesh に MeshFilter のメッシュをセット
5. ObjectSpawner の prefab フィールドに登録
```

> ⚠️ MeshCollider は **Convex = false（デフォルト）** のままにすること  
> Convex=true にすると textureCoord が取れなくなり UV 描画が機能しなくなる

---

### 1-2. 弾丸（インク弾）

#### ✅ 必須要件

| 項目 | 内容 |
|---|---|
| 形状 | インクのしずく・カプセル・球形など |
| ポリゴン数 | 500面以下（毎フレーム大量生成されるため） |
| 中心点 | ジオメトリの中心に置くこと |
| スケール適用 | 必ずスケール適用してからエクスポート |

#### ✅ 弾のサイズ目安

Unity の world scale で直径 0.1〜0.3m 程度（Sphere scale=0.2 相当）

---

### 1-3. UV展開のやり方（Blender初心者向けメモ）

1. Edit Mode（Tab）でオブジェクトを全選択（A）
2. U キーを押して **Smart UV Project** を選択
3. UV Editor で全ての面が重複なく 0〜1 に収まっているか確認
4. 重なっている面は手動で移動・スケールして分離する

> リンゴ・バナナなど有機的な形状は **Unwrap** の方が自然に展開できる

## PART 2：演出アイデア集（凝った体験にするための工夫）

---

### 🎨 ペイント・インク系の演出

#### A. インクのにじみ表現（ぼかし効果）
現在は硬い円形ブラシだが、ガウシアンブラフをかけてにじんだ感じにする  
- アプローチ：GPU シェーダー（Compute Shader）でブラシをリアルタイム処理

#### B. 着弾時のスプラッシュ（飛び散り）
弾がオブジェクトに当たった瞬間に、周囲に小さいインク粒子が飛び散る  
- パーティクルシステム（Particle System）で実現
- 色は InkBullet の `_color` に合わせて動的に変更

#### C. インクが垂れる（重力ドリップ）
塗られた部分から下方向にインクが垂れていくアニメーション  
- テクスチャを毎フレーム下方向にブレンドして擬似的に表現
- または UV スクロールを使って垂れる模様を演出

#### D. 塗り面積によって色の鮮やかさが変わる
塗られた量が増えるほど彩度が上がる・光り輝くエフェクト  
- Shader Graph で Emission を塗り面積に連動させる

#### E. 未塗り部分をグレーアウト
ゲーム開始時はオブジェクトが灰色で、塗られた部分だけカラフルになる  
- マテリアルに「ベース色：グレー」+ 「インクテクスチャをアルファで合成」する設計

---

### ✨ オブジェクト演出系

#### F. オブジェクトがゆらゆら揺れる
まっすぐ移動するだけでなく、Sin 波で上下にゆらゆら動く  
- `FloatingObject.cs` に `Mathf.Sin(Time.time * frequency) * amplitude` を Y に加算

#### G. オブジェクトがスピンしながら流れる
ゆっくり回転しながら移動することで立体感が出る  
- `transform.Rotate(Vector3.up * rotationSpeed * Time.deltaTime)`

#### H. 塗り完了でオブジェクトが弾ける（バースト演出）
オブジェクトを一定割合（例：80%）塗ると爆発エフェクトとともに消える  
- `PaintTarget` でピクセルのアルファ合計を計測してスコアを算出
- 条件を満たしたら Particle を生成して Destroy

#### I. オブジェクトが複数の色でシマシマになる
異なる色の弾を撃つたびに塗り分けが変わる  
- すでに現在の仕組みで実現済み（色が重なるとブレンドされる）

#### J. オブジェクトに「当たり・ハズレ」の絵が描かれている
特定のオブジェクトだけ「塗ってはいけないゾーン」があり、塗ると減点  
- ベーステクスチャに「✗ マーク」などを描いておき、そこを塗ると判定

---

### 🔫 インク銃・発射演出系

#### K. マズルフラッシュ（発射エフェクト）
発射の瞬間だけ銃口付近が光る  
- Light コンポーネントを一瞬 ON にして即 OFF（Coroutine）
- または Particle System で小さなスパークを出す

#### L. 弾がカーブする（重力・風）
まっすぐではなく少し弧を描いて飛ぶことでリアル感が増す  
- `InkBullet.Update()` に `_direction += Vector3.down * gravity * Time.deltaTime` を追加

#### M. 連射時に弾がバラける（散弾）
連射速度が速くなると弾がランダムに広がるショットガン的な動き  
- `Quaternion.Euler(Random.Range(-spread, spread), ...)` で方向をランダムにずらす

#### N. チャージショット（長押しで巨大弾）
長押しするほど大きく・遅い弾になる  
- `InkGun` でボタン長押し時間を計測して `bulletScale` と `brushWorldRadius` を拡大

#### O. 色が混ざる（混色システム）
赤弾と青弾が同じ場所に当たると紫になる  
- 現在の CPU ブラシで Color.Lerp するだけで実現できる（すでに一部対応済み）

---

### 🌟 画面全体・ゲーム演出系

#### P. 背景がだんだん塗られた色に染まる
塗ったインクの色の平均色で背景色が変化していく  
- Camera の Background Color をゲーム中に RenderTexture のピクセル平均から算出

#### Q. 時間が少なくなると画面が点滅・揺れる
残り10秒で画面を赤くフラッシュさせる  
- Post Processing の Color Grading または Screen Overlay Image を使う

#### R. オブジェクトの「流れてくる速度」がゲーム後半に加速する
ゲーム開始からの経過時間に応じて `moveSpeedMax` を上げていく  
- `ObjectSpawner` にタイマーを持たせ、難易度カーブを実装

#### S. ハイスコア表示（後から実装）
塗り面積の合計でスコアを計算して表示  
- `PaintTarget.cs` にピクセルカウント機能を追加
- GameUI で合計スコアを TextMeshPro で表示

#### T. BGM・SE との連動
塗るたびに音が変わる・リズムに合わせてオブジェクトが流れてくる  
- AudioSource の pitch を InkColorCycler の色インデックスに対応させる

---

### 🍎 Blenderモデル専用演出（モデル差し替え後に追加できるもの）

#### U. リンゴ・バナナのリアルな質感
PBR マテリアル（Albedo・Normal・Roughness）を使ってリアルな果物を表現  
- Substance Painter でテクスチャを焼いて URP に適用

#### V. カットアニメーション
インクを塗りきると果物が真っ二つに切れるアニメーション  
- Blender でシェイプキーを作り、Unity の Animation で再生

#### W. 果物がプルプル動く
歩く・揺れるジャイロアニメーションでキャラクターに愛着が出る  
- Blender でリグを組んでアームストロング的な揺れアニメーション

#### X. インクが表面にリアルに乗る（法線マップ対応ブラシ）
凹凸のある表面でインクがへこみに溜まるように見える  
- Normal Map の情報を使ってブラシのアルファを変調させる
