本書は、Unity 側のペイントゲームと連携するために **Blender で制作・エクスポートする 3D アセット一覧とその詳細仕様** を定義する。

## A. マスコットキャラクター

### 目的

Unity の RenderTexture ペイントシステムにより、来場者がリアルタイムで色を塗るメインターゲット。  
**UV 展開の品質がペイント処理の精度に直結するため、最重要アセット。**

### 形状・デザイン仕様

| 項目 | 仕様 |
|---|---|
| モデル種別 | 学校マスコットキャラクター（人型・動物・ゆるキャラ等） |
| スタイル | 学園祭展示向けのかわいらしい・親しみやすいデザイン |
| パーツ分割 | 基本的に 1 メッシュ推奨（UV 重複を避けるため） |
| アーマチュア（ボーン） | 任意。アイドルアニメーションを付ける場合のみ設定 |

### ポリゴン・解像度仕様

| 項目 | 仕様 |
|---|---|
| 頂点数 / ポリゴン数 | 10,000 〜 50,000 ポリゴン推奨（展示 PC の描画負荷に配慮） |
| テクスチャ解像度 | **1024×1024 px**（RenderTexture と解像度を合わせる） |
| ノーマルマップ | オプション（法線マップがあると立体感向上） |

### UV 展開（最重要）

> ⚠️ UV 展開が不完全な場合、Unity 側のペイントが正しく反映されない。

- **Blender の UV Editing ワークスペースを使用する**
- スマート UV 展開（`U → Smart UV Project`）を使用
- **全面を重なりなく UV 空間に展開すること**（島の重複禁止）
- UV 空間（0〜1 の範囲）に全ての UV 島が収まること
- 目・口などペイントが多く当たる部分は UV 島を大きく配置することを推奨

### マテリアル仕様

| 項目 | 仕様 |
|---|---|
| マテリアル数 | 1 つ（Unity RenderTexture との互換性のため） |
| シェーダー | Principled BSDF（PBR 対応） |
| BaseColor | カラーテクスチャまたは単色（白〜薄い色推奨。ペイントが映えるため） |
| Roughness | 0.5 〜 0.8 程度（マット系）。Unity 側で光沢演出するため |
| Normal Map | オプション |
| Emission | 不使用（Unity URP 側で制御） |

### アニメーション（任意）

| 項目 | 仕様 |
|---|---|
| 有無 | 任意。あると展示映えする |
| 内容 | アイドルアニメーション（緩やかな揺れ・呼吸 など） |
| フレームレート | 30fps |
| ループ | ループ再生前提で制作 |

### エクスポート設定（FBX）

| 設定項目 | 値 |
|---|---|
| フォーマット | FBX (.fbx) |
| Apply Scalings | FBX Units Scale |
| Forward | -Z Forward |
| Up | Y Up |
| Apply Transform | ✅ チェックを入れる |
| アーマチュア | ボーンがある場合のみ含める |
| テクスチャ | 外部参照（Unity 側でマテリアルを再設定するため埋め込み不要） |

### 出力先・ファイル名

```
Assets/OmiyaFes2026/Models/MascotCharacter.fbx
Assets/OmiyaFes2026/Textures/MascotCharacter_BaseColor.png  （白または薄色ベース）
Assets/OmiyaFes2026/Textures/MascotCharacter_Normal.png     （任意）
```

### Unity 側での後処理（参考）

- インポート後、マテリアルを **URP Lit シェーダー** に差し替え
- MainTexture に `PaintTexture`（RenderTexture）をセット
- `PaintTarget` タグをキャラクターオブジェクトに付与

## B. インク飛翔弾

### 目的

インク銃から発射される弾オブジェクト。視覚演出用（当たり判定は Raycast で行うため、弾自体の物理は不要）。

### 形状仕様

| 項目 | 仕様 |
|---|---|
| 形状 | インクの滴のような球形 〜 雫形（tearDrop 型） |
| スタイル | 丸みがあり、インクがぷよぷよした印象 |
| サイズ（Blender 内） | 直径 約 0.05 〜 0.1 m（Unity 側でスケール調整可） |

### ポリゴン仕様

| 項目 | 仕様 |
|---|---|
| ポリゴン数 | 500 以下（多数同時生成されるため軽量必須） |
| UV 展開 | 必須ではないが、単純な展開を推奨（基本色のみで可） |

### マテリアル仕様

| 項目 | 仕様 |
|---|---|
| マテリアル数 | 1 つ |
| シェーダー | Principled BSDF |
| BaseColor | 白または中間色（Unity 側でカラーを動的に変更するため） |
| Roughness | 0.1 〜 0.3（光沢感あり、インクらしく） |
| Transmission / Alpha | インクっぽさを出すために半透明可 |

### エクスポート設定

| 設定項目 | 値 |
|---|---|
| フォーマット | FBX または GLB |
| Apply Transform | ✅ |
| アーマチュア | なし |

### 出力先・ファイル名

```
Assets/OmiyaFes2026/Models/InkProjectile.fbx
```

### Unity 側での後処理（参考）

- Prefab 化 → `InkProjectile.prefab`
- Unity 側の `InkColorCycler.cs` が現在の選択色をマテリアルに反映
- `InkGun.cs` から `Instantiate` して使用

## C. インク着弾エフェクト

### 目的

インク弾が命中したときの「インクが広がる」視覚エフェクト。  
アニメーション付きモデル or スプラッシュ形状のメッシュとして制作。

### 形状仕様

| 項目 | 仕様 |
|---|---|
| 形状 | 平たいインクのしぶき・飛散形状 | 
| スタイル | 中心から外側に広がる薄いインク形状（スターバースト状） |
| 向き | XZ 平面に展開（法線が Y 上向き） |
| サイズ（Blender 内） | 半径 約 0.2 〜 0.5 m |

### アニメーション仕様（推奨）

| 項目 | 仕様 |
|---|---|
| 有無 | 推奨（スケールが 0 → 1 → 消える アニメーション） |
| 尺 | 0.3 〜 0.6 秒程度 |
| 内容 | 中心から外に広がり、フェードアウト（Opacity アニメ or Unity 側で制御） |
| ループ | **ループしない**（一度再生して終了） |

> ✅ アニメーションが難しい場合は、静止メッシュのみでも可（Unity 側の DOTween / コルーチンでスケールアニメーションを付ける）。

### ポリゴン仕様

| 項目 | 仕様 |
|---|---|
| ポリゴン数 | 1,000 以下（同時複数生成のため軽量必須） |
| UV 展開 | 推奨（インクテクスチャを貼る場合） |

### マテリアル仕様

| 項目 | 仕様 |
|---|---|
| マテリアル数 | 1 つ |
| シェーダー | Principled BSDF |
| BaseColor | 白または薄色（Unity 側で動的に色付け） |
| Alpha | 半透明対応推奨（周縁部を透明に） |

### エクスポート設定

| 設定項目 | 値 |
|---|---|
| フォーマット | FBX または GLB |
| Apply Transform | ✅ |
| アーマチュア | アニメーションがある場合のみ含める |

### 出力先・ファイル名

```
Assets/OmiyaFes2026/Models/InkSplash.fbx
```

### Unity 側での後処理（参考）

- Prefab 化 → `InkSplash.prefab`
- 着弾時に `Instantiate`、一定時間後に `Destroy`
- DOTween or コルーチンで Scale / Alpha のフェードアウトアニメーション付加

## エクスポート共通チェックリスト

Blender からエクスポートする前に、**全アセット共通**で以下を確認すること。

- [ ] 全オブジェクトのスケール・回転を `Ctrl+A → All Transforms` で適用済み
- [ ] オリジン（原点）がオブジェクトの足元または中心に設定されている
- [ ] シーン内に不要なオブジェクト（カメラ・ライト等）が含まれていない
- [ ] メッシュの面の法線が外向きになっている（`Overlay → Face Orientation` で確認）
- [ ] Ngon（4辺以上のポリゴン）が極力ないこと（三角・四角ポリゴン推奨）
- [ ] UV 展開が UV 空間（0〜1）の範囲内に収まっている（マスコットキャラクターは特に重要）
- [ ] `Apply Scalings: FBX Units Scale` を設定済み
- [ ] `Apply Transform` にチェック済み

## Unity インポート後チェックリスト

| 確認項目 | 担当 |
|---|---|
| FBX をインポートするとスケールが正常か（Scale Factor = 1） | Unity 担当 |
| マテリアルを URP Lit シェーダーに差し替え済みか | Unity 担当 |
| マスコットキャラクターに `PaintTarget` タグを設定済みか | Unity 担当 |
| `RaycastHit.textureCoord` が正しい UV 座標を返すか（デバッグ確認） | Unity 担当 |
| InkProjectile・InkSplash を Prefab 化済みか | Unity 担当 |

## 作業優先度・依存関係

```
[必須・最優先]
  A. マスコットキャラクター（UV展開含む）
      → これが完成しないと Phase 4（ペイントシステム）の実装に進めない

[必須・並行可能]
  B. インク飛翔弾
  C. インク着弾エフェクト
      → Phase 5（発射・着弾処理）の実装に必要
```

> ⚠️ **マスコットキャラクターの UV 展開が最優先タスク。**  
> UV 展開のやり直しは Unity 側の全ペイント実装に影響するため、完成前に Unity 担当と確認すること。
