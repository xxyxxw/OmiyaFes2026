1. プロジェクト概要
================================================================

作品名       : インタラクティブ・ペイントシューター（仮称）
コンセプト   : スマートフォン（iPhone）を傾けて照準を操作し、
               インク銃で学校マスコットキャラクターに色を塗る
               ペイント体験型ゲーム
展示形態     : 学園祭の来場者が1人ずつ体験する参加型インタラクティブアート
プレイ時間   : 1回あたり30秒〜1分程度
参考リポジトリ: https://github.com/uni-bit/yugo-ShibaLab-ARD

【作品の特徴】
- スマホを傾けるだけの直感的操作で、説明不要で楽しめる
- ZIG SIM が iPhone のジャイロデータを UDP/OSC で PC に送信し、
  Unity がリアルタイムで照準を制御する
- 塗った部分がリアルタイムで色変化・スプラッシュエフェクトで
  「塗る気持ちよさ」を演出
- Blender で制作した学校マスコットキャラクターを 3D モデルとして使用
- 最初の設定カラーはカラフルで赤ピンクオレンジ黄色。。。と自動で移り変わる。（後付けで作ります。最初は作りません。カラー選択画面をスクリーン内に作る。インク銃で選択できる。弾速を早くして、球を小さくして選択したい色を打ちやすくする。）

2. 技術スタック・開発環境
================================================================

カテゴリ           | 技術・ツール                        | バージョン / 備考
-------------------|-------------------------------------|---------------------------
ゲームエンジン     | Unity                               | 6000.0.68f1
レンダリング       | Universal Render Pipeline（URP）    | Unity 標準 URP
入力システム       | Unity Input System                  | 新 Input System パッケージ
3D モデリング      | Blender                             | マスコットキャラクター制作
スマホアプリ       | ZIG SIM                             | App Store から無料インストール
通信プロトコル     | UDP + OSC                           | ZIG SIM → PC へジャイロ送信
スクリプト言語     | C#                                  | Unity スクリプト
シェーダー         | ShaderLab / HLSL                    | ペイント演出用

【ZIG SIM とは】
- iPhone のセンサーデータ（ジャイロ・加速度等）を UDP/OSC で
  PC にリアルタイム送信できる iOS アプリ（無料）
- App Store で「ZIG SIM」と検索してインストール
- 設定画面で PC の IP アドレスとポート番号を入力するだけで接続完了
- 送信データはクォータニオン形式のジャイロ情報
- PC 側（Unity）では UdpQuaternionReceiver.cs で OSC パケットを受信

3. システム構成（Unity + ZIG SIM）
================================================================

【全体アーキテクチャ】

コンポーネント             | 役割                                    | 技術
---------------------------|----------------------------------------|------------------
iPhone（ZIG SIM）          | ジャイロデータを UDP/OSC で PC に送信  | ZIG SIM アプリ
PC（Unity）                | OSC 受信・照準計算・3D 描画・ペイント  | Unity 6 + C#
ディスプレイ               | Unity ゲーム画面を表示                  | PC に接続したモニター
Wi-Fi ルーター             | iPhone と PC を同一 LAN で接続          | 同一ネットワーク必須

【通信フロー】
① iPhone の ZIG SIM を起動し、PC の IP アドレスとポート（例：8000）を設定
② ZIG SIM がジャイロのクォータニオンデータを UDP/OSC で PC に送信（毎フレーム）
③ Unity の UdpQuaternionReceiver.cs が OSC パケットを受信
④ QuaternionCoordinateConverter.cs が iOS 座標系 → Unity 座標系に変換
⑤ PoseRotationDriver.cs がスポットライトの向きをジャイロ値で更新
⑥ スポットライトの照射位置 = 照準として 3D モデルにペイント処理
⑦ カラー選択・リセットは PC のキーボードで操作

【参考リポジトリとの対応】

スクリプト                       | 本作品での役割
---------------------------------|------------------------------------
UdpQuaternionReceiver.cs         | ZIG SIM からの OSC/UDP 受信
QuaternionCoordinateConverter.cs | iOS → Unity 座標変換
PoseRotationDriver.cs            | 照準（スポットライト）の向き制御
PoseCalibrationCoordinator.cs    | キャリブレーション（基準点設定）
SpotlightSensor.cs               | スポットライトが 3D モデルに当たっているか判定
PoseTestBootstrap.cs             | 起動時のリグ自動生成・各コンポーネント接続

4. ZIG SIM セットアップ手順
================================================================

【iPhone へのインストール】
1. App Store で「ZIG SIM」を検索
2. 「ZIG SIM」（1-10-0 inc.）をインストール（無料）
3. iPhone の Wi-Fi を展示会場の Wi-Fi ルーターに接続

【ZIG SIM の設定】
1. ZIG SIM を起動 → 右上の設定アイコンをタップ
2. 「IP ADDRESS」に PC のローカル IP アドレスを入力（例：192.168.1.10）
3. 「PORT」に Unity 側が受信するポート番号を入力（例：8000）
4. 「PROTOCOL」を「UDP」に設定
5. 「SENDER FORMAT」を「OSC」に設定
6. 「GYROSCOPE」または「QUATERNION」を ON にする
7. 「START」ボタンを押して送信開始

================================================================
5. ジャイロ入力仕様（UDP/OSC）
================================================================

【受信データ仕様】

項目         | 内容
-------------|------------------------------------------------
送信元       | iPhone（ZIG SIM）
受信先       | PC（Unity：UdpQuaternionReceiver.cs）
通信方式     | UDP
データ形式   | OSC メッセージ
データ内容   | クォータニオン（x, y, z, w）＝スマホの向き・傾き
送信ポート   | 8000 番（任意。Unity 側と合わせる）
送信レート   | ZIG SIM 設定による（推奨：60fps）

【操作とゲーム内動作の対応】

スマホの操作               | ゲーム内の動作                    | 処理スクリプト
---------------------------|----------------------------------|---------------------------
スマホを左右に傾ける       | 照準（スポットライト）が左右移動  | PoseRotationDriver.cs
スマホを前後に傾ける       | 照準（スポットライト）が上下移動  | PoseRotationDriver.cs
スマホをニュートラルに向ける| 照準が画面中央付近に戻る         | PoseCalibrationCoordinator.cs
C キー（PC 側）            | 現在の向きを基準点に設定         | PoseCalibrationCoordinator.cs

【座標変換】
- iOS のジャイロ座標系は Unity の座標系と異なるため変換が必要
- QuaternionCoordinateConverter.cs で変換（参考リポジトリ実装を流用）
- iOS：右手系、Y 軸が画面上方向
- Unity：左手系、Y 軸が上方向

6. ゲームロジック設計
================================================================

【ゲームの流れ】

フェーズ           | 内容                                              | 時間
-------------------|--------------------------------------------------|----------
① 待機画面         | Unity が待機中の画面を表示。ZIG SIM の接続待ち   | —
② ZIG SIM 接続     | 来場者が ZIG SIM を起動・設定してデータ送信開始  | 〜30 秒
③ キャリブレーション| スタッフが C キーを押してジャイロ基準点を設定    | 〜5 秒
④ ゲームプレイ     | タイマースタート。傾けて照準を動かし塗る          | 30 秒〜1 分
⑤ 結果表示         | 塗り面積・達成率を Unity 画面に表示               | 5〜10 秒
⑥ リセット         | PC の R キーで初期化 → 待機画面へ戻る            | 即時

【ペイント処理】
- SpotlightSensor.cs でスポットライトが 3D モデルのどこに当たっているか判定
- 照射された面の UV 座標にインクテクスチャを描画（DynamicTexture）
- インク発射時は円形に広がるスプラッシュエフェクトを Shader で演出
- 選択中のカラーで上書き塗り可能
- 塗り面積はテクスチャの色付きピクセル数から算出

【スコア・目標設定】
- 目標：制限時間内にマスコットキャラクターの塗り面積を最大化
- 塗り面積をパーセンテージでリアルタイム HUD 表示
- ランキングは実装しない（シンプルさ・短時間プレイ優先）

7. UI設計
================================================================

【スマホ画面（ZIG SIM）】
- ZIG SIM のジャイロ可視化画面のみ表示
- カスタムボタン等の UI は作成不可のため、スマホ側の操作はジャイロのみ

【Unity 画面（PC・ディスプレイ）】
- 3D マスコットキャラクターをメイン表示
- スポットライト照射位置を照準として可視化（光の円形）
- 残り時間・塗り面積（%）を HUD としてオーバーレイ表示
- インクスプラッシュエフェクトを Shader でリアルタイム描画
- 待機中は「ZIG SIM でジャイロを送信してください」の案内を表示

【PC キーボード操作（スタッフ用）】
- R キー：塗りをリセット
- C キー：ジャイロキャリブレーション
- D キー：デバッグオーバーレイ表示切替
- F11 キー：フルスクリーン切替

8. 3Dモデル連携仕様（Blender → Unity）
================================================================

【Blender での制作・エクスポート仕様】

項目               | 仕様
-------------------|--------------------------------------------------
推奨フォーマット   | FBX または GLB（GLTF Binary）
Unity インポート形式| FBX 推奨（Unity は FBX を直接サポート）
エクスポート設定   | Apply Transforms にチェック、スケール 1.0
ポリゴン数目安     | 10,000〜50,000 ポリゴン
UV 展開            | 全面にUV展開が必要（スマート展開を使用）
マテリアル         | PBR 対応（BaseColor / Roughness / Normal）、URP 対応
テクスチャ解像度   | 1024×1024 または 2048×2048
ボーン・アニメーション| 任意（アイドルアニメがあると展示映えする）

【Unity でのペイント実装方針】
- SpotlightSensor.cs の IsLit / Exposure01 値を使い照射面を特定
- 照射 UV に RenderTexture へ描画する方式でペイントテクスチャを生成
- 描画結果を Material の MainTexture にリアルタイム反映
- URP のカスタムシェーダーでスプラッシュエフェクトを演出

【Blender エクスポート手順】
1. モデルを完成させ、全オブジェクトを選択
2. UV Editing ワークスペースでスマート UV 展開（U → Smart UV Project）
3. File > Export > FBX (.fbx) を選択
4. 「Apply Scalings：FBX Units Scale」「Forward：-Z Forward」「Up：Y Up」に設定
5. 「Apply Transform」にチェックを入れて Export
6. Unity の Assets フォルダに FBX ファイルをドラッグ＆ドロップでインポート

9. 展示環境セットアップ
================================================================


【展示当日のセットアップ手順】
1. PC とディスプレイを HDMI で接続
2. 持参 Wi-Fi ルーターに PC を接続し、PC のローカル IP アドレスを確認
3. Unity で Build した exe（または Unity Editor）を起動
4. 展示用 iPhone の ZIG SIM を起動し IP アドレス・ポートを確認
5. ZIG SIM の START を押してデータ送信開始
6. Unity 側で C キーを押してキャリブレーション実施
7. ゲームスタート！
