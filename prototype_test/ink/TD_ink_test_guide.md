# TouchDesigner インク質感テスト 完全設計書
## スプラ3風「厚みのあるリアルなインク」を作る

---

## はじめに読んでください

この設計書は **「TouchDesignerをインストールしたばかりで何もわからない」** 状態から、
スプラトゥーン3風の厚みのあるインク表現を作るための手順書です。

**この設計書でやること：**
1. TouchDesignerの基本操作を覚える（10分）
2. インクの質感テスト用のノード構成を組む（30分）
3. 見た目を調整してスプラ3に近づける（自由）

**やらないこと（今回はスコープ外）：**
- ジャイロセンサーとの接続
- 多人数対応
- プロジェクター出力設定

まずインクを「かっこよく」することだけに集中します。

## 第1章：TouchDesignerの基本操作（必ず読む）

### 1-1. 画面の構成を理解する

起動すると以下の画面が見えています。

```
┌─────────────────────────────────────────────┐
│ メニューバー（File, Edit, Dialogs...）          │
├──────────┬──────────────────────┬────────────┤
│          │                      │            │
│ Palette  │  ネットワークエディタ  │ パラメータ  │
│ (左パネル) │  （真ん中・一番重要） │ (右パネル) │
│          │                      │            │
├──────────┴──────────────────────┴────────────┤
│ タイムライン（下）                              │
└─────────────────────────────────────────────┘
```

**一番重要なのは「ネットワークエディタ」（真ん中の黒いエリア）です。**
ここにノード（部品）を置いて、繋いでいくことで映像を作ります。

---

### 1-2. ノードとは何か

TouchDesignerはノードベースのソフトです。
「ノード」= 処理の部品、と思ってください。

```
[ノードA] ──→ [ノードB] ──→ [ノードC] ──→ 出力
 (素材)        (加工)        (仕上げ)
```

レゴブロックを繋げるイメージです。
左から右へデータが流れていきます。

---

### 1-3. ノードの種類（色で覚える）

| 色 | 種類 | 略称 | 役割 |
|---|---|---|---|
| 青紫 | Texture Operator | **TOP** | 映像・画像の処理（今回メイン） |
| 緑 | Component | **COMP** | カメラ、ライト、3Dオブジェクト |
| 黄緑 | Channel Operator | **CHOP** | 数値データ（ジャイロ値など） |
| 茶 | Surface Operator | **SOP** | 3D形状 |
| 紫 | Material | **MAT** | 質感・マテリアル |
| 白 | Data Operator | **DAT** | テキスト・データ |

**今回主に使うのは TOP（青紫）と COMP（緑）と MAT（紫）です。**

---

### 1-4. 基本操作のキーボードショートカット

| 操作 | 方法 |
|---|---|
| ノードを追加する | ネットワークエディタ上で **Tabキー** を押す |
| ノードを削除する | クリックして選択 → **Deleteキー** |
| 画面を移動する | **中クリック + ドラッグ** または **Alt + 左ドラッグ** |
| ズームイン/アウト | **スクロール** |
| ノードを繋ぐ | ノードの右端の小さい点から **ドラッグ** して次のノードの左端へ |
| ノードのプレビューを見る | ノードを **左クリック** |
| 全体を見渡す | **Homeキー** |
| ノードを検索して追加 | Tab → 名前を入力 |

## 第2章：インク質感テストの設計

### 2-1. 今回作るものの全体像

最終的にこういうノード構成を組みます：

```
[Noise TOP]
    │
    ▼
[Level TOP]  ← 明るさ調整
    │
    ▼
[Normal Map TOP]  ← 高さ情報から法線を生成（これが厚みの核心）
    │
    ▼
[Render TOP] ← [Geometry COMP] + [Light COMP] + [Camera COMP]
    │               │
    │           [Sphere SOP] + [Phong MAT]（法線マップを貼る）
    ▼
[Out TOP]  ← 最終出力
```

**何をやっているか：**
1. `Noise TOP` でランダムなグレースケール画像を作る（これがインクの「高さ」）
2. `Normal Map TOP` で高さの変化を「法線（光の当たり方）情報」に変換
3. `Render TOP` で3Dライティングを適用 → 盛り上がって見える！
4. 最終的に `Out TOP` でスクリーンに出力

---

### 2-2. まず最初に：新しいプロジェクトを作る

1. メニューバーから **File → New** をクリック
2. 保存場所を聞かれたら、デスクトップなど分かりやすい場所に
   `ink_test.toe` という名前で保存
3. ネットワークエディタが真っ黒になっていればOK

---

## 第3章：ノードを組んでいく（ステップバイステップ）

### STEP 1：Noise TOPを置く（インクの形を作る）

**Noise TOP = ランダムなグレースケール模様を作るノード**
これがインクの「高さマップ」になります。

**手順：**
1. ネットワークエディタの黒いエリアをクリック（フォーカスを当てる）
2. **Tabキー** を押す → ノード検索ダイアログが開く
3. `noise` と入力 → `Noise` が出てくる → **Enterキー** または ダブルクリック
4. ネットワーク上にノードが置かれる

**ノードをクリックして右パネル（パラメータ）を確認：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Type | `Sparse` | インクっぽいモコモコした形になる |
| Period | `0.5` | 模様の大きさ（小さいほど細かい） |
| Amplitude | `1.0` | 強さ（そのままでOK） |

> ノードの上にグレーの模様が表示されていれば成功です。

---

### STEP 2：Level TOPを追加する（明暗を強調する）

**Level TOP = 明るさ・コントラストを調整するノード**
インクの「塗られている/塗られていない」の境界をくっきりさせます。

**手順：**
1. Tabキー → `level` と入力 → `Level` を選択
2. Noise TOPの**右側**に置く
3. **Noise TOPの右端の点** から **Level TOPの左端** へドラッグして繋ぐ

**パラメータ設定：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Black Level | `0.3` | 暗い部分をカット → インクの境界が明確に |
| White Level | `0.8` | 明るい部分を引き締める |
| Gamma | `0.8` | 中間部分のコントラスト強調 |

> コントラストが強くなってインクっぽい形になればOKです。

---

### STEP 3：Normal Map TOPを追加する（厚みの核心）

**Normal Map TOP = グレースケール画像を「でこぼこの法線情報」に変換するノード**
これがスプラ3の「盛り上がったインク」の質感の核心です。

**手順：**
1. Tabキー → `normal` と入力 → `Normal Map` を選択
2. Level TOPの右側に置く
3. Level TOP → Normal Map TOP に繋ぐ

**パラメータ設定：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Strength | `3.0` | 法線の強さ（大きいほど凹凸が激しい） |
| Filter | `Sobel` | 境界の検出方式（Sobelが一番自然） |

> ノードの表示が青紫っぽい「法線マップ」の色合いになればOKです。

---

### STEP 4：3Dシーンを作る（ライティングで質感を出す）

ここが一番重要で、少し複雑です。ゆっくり進めてください。

**4-1. Geometry COMPを追加する（3Dオブジェクトの入れ物）**

1. Tabキー → `geo` → `Geometry` を選択
2. ネットワーク上に置く（位置はどこでもOK、少し離れた場所に）
3. Geometry COMPを**ダブルクリック** → 中に入る（パスが `/project1/geo1` になる）

**4-2. Geometry COMPの中にPlane SOPを置く**

Geometry COMPの中（ダブルクリックで入った状態）で：

1. Tabキー → `plane` → `Plane` を選択
2. そのままネットワーク上に置く

**Plane SOPのパラメータ：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Size X | `2.0` | 横幅 |
| Size Y | `2.0` | 縦幅 |
| Rows | `100` | 分割数（多いほど滑らかな凹凸になる） |
| Columns | `100` | 同上 |

**4-3. Phong MATを追加する（質感・マテリアル）**

Geometry COMPの中で：

1. Tabキー → `phong` → `Phong` を選択
2. Plane SOPの右側に置く
3. Plane SOP → Phong MAT に繋ぐ

**Phong MATのパラメータ（「Texture」タブをクリックして設定）：**

> **重要！** Phong MATを選択して右パネルを見ると上部にタブがあります。
> `Phong` / `Texture` / `Bump` / `Vector` などのタブです。

まず **Phong タブ** を設定：

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Color（Diffuse） | 好きな色（例：R:0.2 G:0.5 B:1.0 = 青） | インクの色 |
| Specular Color | R:1.0 G:1.0 B:1.0（白） | ハイライトの色 |
| Shininess | `80` | 光沢の鋭さ（大きいほどテカテカ） |

次に **Bump タブ** を設定（これで凹凸が出る！）：

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Bump Map（TOP） | `Normal Map TOPのパス` | ここに法線マップを指定 |
| Bump Depth | `1.0` | 凹凸の深さ |

> Bump MapのTOPにNormal Map TOPを指定する方法：
> Bump Mapのフィールドに、Normal Map TOPの**ノード名**（例：`normalmaptop1`）を入力します。
> またはフィールドをクリックして、Normal Map TOPを**ドラッグ&ドロップ**でもOKです。

**4-4. Geometry COMPの外に出る**

ネットワーク上部のパスバーで `/ project1` をクリック → 外に戻る

---

### STEP 5：Light COMPとCamera COMPを追加する

ライトがないと3Dは真っ暗になります。

**Light COMPを追加：**
1. Tabキー → `light` → `Light` を選択
2. ネットワーク上に置く

**Lightのパラメータ：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Light Type | `Point` | 点光源（インクに影が出やすい） |
| Tx / Ty / Tz | `1.0 / 1.5 / 1.0` | ライトの位置（斜め上から当てる） |
| Intensity | `1.5` | ライトの強さ |
| Color | 白（1,1,1）| 白色ライト |

**Camera COMPを追加：**
1. Tabキー → `camera` → `Camera` を選択
2. ネットワーク上に置く

**Cameraのパラメータ：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Tz | `3.0` | カメラのZ位置（離れるほど広く見える） |

---

### STEP 6：Render TOPで3Dシーンをレンダリングする

**Render TOP = 3Dシーンを映像として書き出すノード**

1. Tabキー → `render` → `Render` を選択
2. ネットワーク上に置く（Geometry, Light, Cameraとは別の場所に）

**Render TOPのパラメータ：**

| パラメータ名 | 設定値 | 理由 |
|---|---|---|
| Camera | `camera1` | 先ほど作ったCameraのノード名 |
| Render | **ここが重要！** | Geometry, Lightを両方追加する |

> **Renderのリストへの追加方法：**
> `Render` パラメータの右にある `+` ボタンをクリック
> → `geo1`（Geometry）と `light1`（Light）を追加

**Resolution（解像度）の設定：**

| パラメータ名 | 設定値 |
|---|---|
| Resolution | `1280 x 720` |

> Render TOPに3Dのインクが表示されれば大成功です！

---

### STEP 7：Out TOPで出力する

1. Tabキー → `out` → `Out` を選択
2. Render TOPの右側に置いて繋ぐ

これで最終出力が完成です。

## 第4章：見た目をスプラ3に近づける調整

### 4-1. インクの色を変える

**Phong MAT** → **Phong タブ** → **Diffuse Color** を変更

| 色の例 | RGB値 |
|---|---|
| オレンジ（スプラっぽい） | R:1.0, G:0.4, B:0.0 |
| 青紫 | R:0.3, G:0.0, B:0.9 |
| 黄緑 | R:0.5, G:1.0, B:0.0 |
| ピンク | R:1.0, G:0.2, B:0.6 |

---

### 4-2. 盛り上がりをもっと強くする

| ノード | パラメータ | 変更値 | 効果 |
|---|---|---|---|
| Normal Map TOP | Strength | `3.0` → `6.0` | 凹凸をより急にする |
| Phong MAT | Bump Depth | `1.0` → `2.0` | 凹凸の視覚的強度を上げる |
| Phong MAT | Shininess | `80` → `200` | より鋭い光沢（テカテカ感） |

---

### 4-3. インクの形を変える

| ノード | パラメータ | 変更値 | 効果 |
|---|---|---|---|
| Noise TOP | Type | Sparse → Hermite | より流れるような形 |
| Noise TOP | Period | `0.5` → `0.2` | 細かい模様 |
| Noise TOP | Period | `0.5` → `1.5` | 大きい塊 |
| Level TOP | Black Level | `0.3` → `0.5` | インクの「密度」を下げる |

---

### 4-4. ライトの位置で質感が劇的に変わる

**Light COMP** のTx/Ty/Tzを変えると光の当たり方が変わります。

| ライト位置の例 | 設定値 | 見た目 |
|---|---|---|
| 真上から | Tx:0, Ty:3, Tz:0 | フラットな印象 |
| 斜め前上から（推奨） | Tx:1, Ty:2, Tz:2 | 凹凸が一番わかりやすい |
| 横から | Tx:3, Ty:0, Tz:1 | ドラマチックな陰影 |

## 第5章：よくあるトラブルと解決法

### Q. ノードを繋いだのに映像が変わらない

→ ノードを繋いだ後、変化が出ない場合は**Render TOPのパラメータを確認**してください。
　 CameraとGeometryが正しく指定されているか確認。

---

### Q. 3Dが真っ暗で何も見えない

→ **Light COMPが追加されているか**確認。
　 Render TOPの`Render`リストに`light1`が入っているか確認。

---

### Q. 「Normal Map TOP」が見つからない

→ Tabキー後に `normalmap` と入力してみてください（スペースなし）。

---

### Q. FPS（フレームレート）が下がってカクカクする

→ Noise TOPやRender TOPの **Resolution** を下げてください。
　 `1280x720` → `640x360` にするとかなり軽くなります。

---

### Q. パラメータのタブが見当たらない

→ 右パネルの上部、ノード名の下に小さいタブが並んでいます。
　 もし見えない場合は右パネルを広げてみてください（境界線をドラッグ）。

---

## 第6章：完成したら次にやること

インクの質感が満足いく状態になったら、次のステップへ進みます：

1. **アニメーション化** → Noise TOPの `Time` パラメータを有効にして動かす
2. **インクが広がる表現** → `Feedback TOP` を使って塗った跡を蓄積する
3. **ZIG SIMとの接続** → CHOP In / OSC In CHOP でジャイロ値を受け取る
4. **色を複数にする** → Composite TOPで複数レイヤーを合成する
